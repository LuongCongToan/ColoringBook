Dùng tài khoản cá nhân. Cả Cloudflare lẫn Anthropic đều đăng ký bằng email cá nhân của bạn, không dùng tài khoản của nhóm hay công ty. API key Anthropic tiêu tiền thật.

1Kiểm tra Node.js trên máy

Mọi lệnh bên dưới (npm, npx) đều cần Node.js. Mở terminal và chạy:

node --version
npm --version
  • Cả hai in ra số phiên bản: sang mục 2.
  • Báo "not found" / "not recognized": cài bản LTS từ nodejs.org, sau đó mở terminal mới rồi chạy lại hai lệnh trên. Terminal đang mở sẵn không nhận PATH mới.

Lệnh là npx (n-p-x). Gõ nhầm thành nox cũng ra lỗi "not found".

2Đăng ký Cloudflare

Gói miễn phí là đủ cho Worker này, kể cả Durable Object (loại SQLite) dùng để đếm hạn mức. Không cần thẻ.

  1. Mở dash.cloudflare.com/sign-up, đăng ký bằng email và mật khẩu.
  2. Mở hộp thư, bấm link xác minh email. Chưa xác minh thì deploy sẽ bị từ chối.
  3. Nếu Cloudflare hỏi thêm domain hay chọn gói: bỏ qua, Worker không cần domain riêng.
  4. Mở trang Workers bằng link trực tiếp: dash.cloudflare.com/?to=/:account/workers-and-pages. Tìm bằng tay thì nó nằm ở thanh bên trái, nhóm Compute → Workers & Pages.
  5. Ở cột phải, ô Account details có dòng Subdomain. Đó là phần đuôi của mọi URL Worker. Chưa có thì bấm biểu tượng bút chì để đặt.
Tài khoản hiện tại đã có subdomain pt-team2011.workers.dev. Không cần bấm Create application: Worker tự xuất hiện trong danh sách sau khi deploy từ terminal.

Nếu bạn thấy trang "Get started by adding your first chart" thì đó là phần Analytics, chưa phải Workers. Dùng link trực tiếp ở bước 4.

3Đăng ký Anthropic và lấy API key

Tài khoản API tách biệt với gói Claude trả tháng (claude.ai, Claude Code). Có gói đó không có nghĩa là có credit API.

  1. Mở console.anthropic.com và đăng ký bằng email cá nhân. Có thể phải xác minh số điện thoại.
  2. Vào Billing, thêm thẻ và nạp credit. Mức nạp nhỏ nhất là đủ: mỗi lượt chấm tốn khoảng $0,00017.
  3. Vào Limits, đặt giới hạn chi tiêu hàng tháng (ví dụ $10). Đây là lớp chặn cuối cùng nếu Worker có lỗ hổng.
  4. Vào API Keys → Create Key, đặt tên dễ nhận ra (ví dụ haru-check-prod).
  5. Copy key ngay (dạng sk-ant-...). Key chỉ hiện một lần; lỡ đóng thì tạo key mới.
Key chỉ đi một chỗ: dán vào khi wrangler secret put hỏi (mục 6). Không lưu vào file trong repo, không dán vào chat, không commit. Nếu lỡ lộ, vào API Keys xoá key đó và tạo key mới.

Tên các mục trong console (Billing, Limits, API Keys) có thể đổi theo thời gian; nếu không thấy thì tìm trong phần Settings.

4Chạy test ở máy

Miễn phí, không cần mạng, không cần key: test dùng fetch giả nên không bao giờ gọi Anthropic.

cd Worker
npm install
npm test
npm run typecheck

Phải thấy 66 test qua. Có test fail thì dừng ở đây, đừng deploy.

5Đăng nhập wrangler

Vẫn đứng trong thư mục Worker:

npx wrangler login

Trình duyệt mở ra, đăng nhập Cloudflare và bấm Allow. Kiểm tra đã đăng nhập đúng tài khoản:

npx wrangler whoami

6Deploy staging rồi production

Staging (cho TestFlight)

npx wrangler secret put ANTHROPIC_API_KEY --env staging
npm run deploy:staging

Production

npx wrangler secret put ANTHROPIC_API_KEY
npm run deploy
  • secret put hỏi giá trị, dán key vào rồi Enter. Màn hình không hiện key là bình thường.
  • Staging và production là hai Worker riêng nên phải đặt secret hai lần. Dùng chung một key hoặc tạo hai key đều được.
  • npm run deploy chạy typecheck và test trước; có test fail thì không deploy.
  • Lần đầu, secret put hỏi có tạo Worker mới không: trả lời Y.
  • Lệnh production in cảnh báo "Multiple environments are defined... no target environment was specified". Chỉ là cảnh báo: không ghi --env nghĩa là production, cứ dán key như thường.
  • Secret chỉ cần đặt một lần. Những lần deploy sau chỉ chạy npm run deploy.

URL thật là dòng wrangler in ra sau khi deploy. Hai URL trên suy từ subdomain hiện tại; nếu đổi subdomain thì URL đổi theo.

7Nối app vào Worker

Mở Shared/AI/SentenceCheckClient.swift, sửa hằng số endpoint thành URL production kèm /check:

static let endpoint = URL(string: "https://haru-check.pt-team2011.workers.dev/check")!

Sau đó tick hai mục "Deploy Worker chấm câu" và "Sửa SentenceCheckClient.endpoint" trong TODO.md.

8Kiểm tra Worker đang sống

curl -i -X POST https://haru-check.pt-team2011.workers.dev/check -H "Content-Type: application/json" -d "{}"

Nhận về 400 hoặc 401 là đúng: Worker đang chạy và từ chối request không có giao dịch hợp lệ, trước khi gọi Anthropic. Lần thử này không tốn tiền.

Muốn thử chấm câu thật thì cần một JWS thật từ bản TestFlight, gửi vào bản staging.

Xem log trực tiếp khi đang thử:

npx wrangler tail
npx wrangler tail --env staging

9Lỗi hay gặp

Triệu chứngNguyên nhân và cách sửa
npx / npm not foundChưa cài Node.js, hoặc terminal mở trước khi cài. Xem mục 1.
Không thấy Workers & PagesĐang ở trang khác của dashboard. Dùng link trực tiếp ở mục 2.
Deploy báo cần xác minh emailBấm link xác minh Cloudflare đã gửi vào hộp thư.
Deploy hỏi đăng ký subdomain workers.devTài khoản chưa có subdomain. Trả lời ngay trong terminal hoặc đặt ở dashboard (mục 2, bước 5).
Wrangler deploy nhầm tài khoảnChạy npx wrangler whoami. Sai thì npx wrangler logout rồi login lại.
npm run deploy dừng giữa chừngCó test hoặc typecheck fail. Đọc lỗi, sửa, chạy lại; đừng gọi thẳng wrangler deploy để bỏ qua.
App luôn nhận "thử lại sau" (503)Chưa đặt ANTHROPIC_API_KEY cho đúng môi trường, key sai, hoặc tài khoản Anthropic hết credit.
App luôn mở paywall (401/403)Bundle ID hoặc product ID trong Worker/src/config.ts không khớp app. Chạy python -E -P Tools/check_worker.py.
